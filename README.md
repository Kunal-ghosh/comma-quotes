# Comma Quote

A simple online tool to format text with customizable separators and quotes.

## Features

- **Multiple separators**: comma, semicolon, pipe, space, newline, tab
- **Quote options**: none, single, or double quotes
- **Smart parsing**: handles line-separated or comma-separated input
- **One-click copy** to clipboard
- **Responsive design** for mobile and desktop

## Usage

1. Enter text in the input area
2. Choose separator and quote style
3. Copy the formatted output

## Example

**Input:**
```
apple
banana
orange
```

**Output:**
```
'apple', 'banana', 'orange'
```

## Tech Stack

- HTML5, CSS3, Vanilla JavaScript
- No dependencies
- Works in all modern browsers

## Setup

Just open `index.html` in your browser. No installation needed.
